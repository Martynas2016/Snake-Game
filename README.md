# Snake
I really enjoyed making this project because it had a lot of detail and learning curves. I would not say that now I know how to make games, but I realized that the more practice you have the more patterns you can spot and knowledge starts growing on you.

One part of code that made me feel cool even though it’s not a major breakthrough is literally turning off automatic redrawing and updating the screen every 0.1s making the game about 10fps.
